# branch exercise

> Here we present an exercise to get you acquainted with the branching workflow of gidhub.

1. go to your repository and navigate to the branch menu and create a new branch. this can be found under code.

2. for the branch name you should use a name that describes what it is for. such as "practicum_week1" check that the source is set to your own repo and that it branches of the main branch. 

now that you have a branch you need to select it as your working branch in VSC. 

3. open VSC and navigate to your reposetory. open the Source Contol pannel on the left (Ctrl + shift + g) where your reposetory should listed under "Repositories"
